# 矩阵云 · 社媒运营工作台

用于登记多平台账号、回填数据、生成复盘和准备发布清单。可直接部署到 GitHub Pages。

## 更新现有站点

将新版 **index.html** 覆盖上传到仓库 **main** 分支的根目录，然后提交更改。仓库已有的 **.nojekyll** 可以保留，**README.md** 可随新版一同更新。若用 ZIP，将压缩包里的文件解压后上传到仓库根目录。

提交完成后，可在仓库的 **Actions** 查看 Pages 部署进度。部署完成后刷新原网址即可。此项目无需安装依赖或运行构建命令。

## 使用工作台

- **账号矩阵**支持添加、编辑和删除本地登记，支持按平台查看，也可隐藏或恢复演示账号。账号的「进入账号」可打开官方后台。已填写的公开主页可从同一菜单访问。
- **数据回填**支持手动录入和 CSV 导出。配置支持图片的 AI 接口后，也可上传截图识别。账号卡片和数据总览展示各账号日期最近的一条回填记录。
- **AI 复盘**可以用本地模板生成。调用自选 AI 接口时会向该服务发送复盘所需的运营数据，截图识别时会发送所选截图。
- **内容发布**导出 TXT 清单，包含文案、平台、媒体文件名和已填写的计划时间。到官方后台完成发布。媒体原文件仍从你的设备选取。
- 发布日历、互动消息、内容审核、素材库和团队权限包含演示功能。

## 浏览器数据

账号、分类、回填记录、草稿、AI 配置和本地入口设置保存在当前浏览器。用同一浏览器访问原网址可继续读取已有数据。换浏览器、换设备或清除该网站的数据后，需要重新登记。回填记录可从「数据回填」导出。

本地口令和本地邮箱入口用于锁定这台浏览器的界面。口令重置只会移除本地入口设置。平台密码请在各平台登录页输入。AI 密钥请在工作台的设置中填写，避免写入公开仓库。
